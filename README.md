# WeekPact

Plan next week's internet rules, review them, and commit. You may tighten a committed rule immediately; a request to loosen it waits at least seven days and cannot alter an already committed week.

WeekPact is a proposed macOS app for user-defined websites and services. It is currently in the **design stage**. Read the [design document](docs/DESIGN.md) for the experience, enforcement limits, and first build milestone.
